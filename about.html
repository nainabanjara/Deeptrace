ABOUT THE PROJECT

Digital safety, made clear.

DeepTrace turns basic digital investigation checks into simple explanations anyone can understand.

D

What is DeepTrace?

DeepTrace is a responsive web application for checking suspicious links, messages and domain names. It stores investigation results in a local SQLite database and creates reports that users can revisit.

Built withPythonFlask backend
Data storageSQLiteLocal database
Works onAll screensPhone and laptop browsers

What DeepTrace does not do

  • It does not guarantee that a website is safe or unsafe.
  • It does not access private accounts or private messages.
  • It does not identify the person behind a phone number or email address.
  • It does not replace professional security tools or official reporting services.
